## 一、总体评分

# 7.5 / 10

**一句话结论**：这是一套**底盘相当扎实**的盯盘前端（懒加载、轮询门禁、对比度修正、`prefers-reduced-motion`、表格 a11y、搜索防抖都做过了），扣分几乎全部集中在**"盯盘三件套"**——**窄屏横滑丢股票身份**、**右栏多日表无上限/无虚拟化**、**数字变化零视觉反馈**——外加颜色/断点/数字格式三处工程收敛问题。

| 维度 | 评分 | 依据摘要 |

## 三、问题清单

### P0 · 必须改（直接影响交易判断）

#### P0-1 窄屏/手机横滑后**丢失股票身份**（首列不冻结）
- **位置**：`frontend/src/styles/main.css` 768 断点块（`.stock-table{min-width:880px;table-layout:auto!important}`）+ `frontend/src/components/StockTable.vue:17-35`（`<colgroup>` 固定像素列宽）
- **问题**：移动端靠 `overflow-x:auto` 横滑 880px 宽表；全站 `position: sticky` 只有 `top`（表头），**无 `left` 冻结列**（grep `sticky; left` 仅命中 toast 的 `position:fixed`）。横滑到「评分/可信/概念」后，屏幕上没有任何字段能告诉你"这是哪只票"——这是盯盘场景最痛的失误点。
- **建议改法**（~10 行 CSS）：
```css
/* main.css 的 @media (max-width:768px) 块内 */
.stock-table thead th:nth-child(1),
.stock-table tbody td:nth-child(1){
  position: sticky; left: 0; z-index: 7;
  background: var(--bg-panel-solid);        /* 必须不透明，否则横向穿帮 */
  box-shadow: 6px 0 8px -6px rgba(0,0,0,.65);  /* 用投影代替边框，避免列宽抖动 */
}
.stock-table thead th:nth-child(1){ z-index: 9; }   /* 左上角交点压过其它 th */
```
  配套：冻结首列时把 `table-layout:auto` 换成 `fixed` 并给首列显式宽度（`StockTable.vue:17-35` 的 colgroup 已有宽度，可直接复用），否则冻结列宽度会随内容跳动。
  同理右侧多日表 `.msd-row`（CSS Grid，见 `AuctionView.vue:1342-1352`）建议把名称格 `grid-area` 固定在第 1 列并加 `position:sticky;left:0`。
- **改动量**：**小**

#### P0-2 右栏「竞价异动多日对比表」无行数上限、无虚拟化、单票 32 个 DOM
- **位置**：`frontend/src/views/AuctionView.vue:121-165`（模板）、`:128` `v-for="day in dailyDays"`、`:150` `v-for="it in day.rows"`、`:153-161`（每票 8 个 `<span class="msd-cell">`）、`:481` `const DAILY_DAYS = 4`、`:1425` `.msd-body{overflow:visible}`（注释明确"整页滚、不做列内裁剪"）
- **问题**：**每票 32 个 span**（4 日 × 8 格）× 行数**无上限**（对比：`AipickReport.vue:298` 有 `MAX_ROWS = 150`；`HistoryView.vue:189` 有"加载更多"）→ 封单榜 300 行即 ~9,600 节点，500 行即 16,000 节点，且 30 s 轮询会**整列重建**。这是"盯盘中断"（掉帧/滚动卡）的第一来源。
- **建议改法**（限行 + CSS 级虚拟化，不引库）：
```js
// AuctionView.vue <script setup> 顶部
const MAX_ROWS_MSD = 300                       // 与 AipickReport.MAX_ROWS 同一策略
const msdRows = rows => rows.slice(0, MAX_ROWS_MSD)
```
```html
<!-- :150 处改为 v-for="it in msdRows(day.rows)" -->
```
```css
/* AuctionView.vue <style scoped> */
.msd-row { content-visibility: auto; contain-intrinsic-size: auto 34px; }
```
  并在该表表头右端显示「已显示 300 / 512」提示（复用 `HistoryView` 的文案风格）。
- **改动量**：**小~中**

#### P0-3 数字变化**零反馈**，且涨跌**颜色是唯一载体**
- **位置**：`StockTable.vue:53`（`:key="item.code"`，稳定键 ⇒ 数据更新只是就地改字符串）；全库 `▲ ▼ ↑ ↓` grep = **0 处**；涨跌色 `main.css:748`（`.up{color:#ff8a6f}` / `.down{color:#00c864}`）
- **问题**：30 s 轮询后"现涨/竞涨/实体"变了，肉眼无感知，必须逐格重读（与"更快看到数字"直接冲突）；同时红/绿是**唯一**信息通道，色弱用户（约 8% 男性）无法区分涨跌。
- **建议改法**（一次性闪一下，不做位移/过渡，符合"克制"约束）：
```vue
<!-- StockTable.vue：让值变化触发一次性闪烁 -->
<td class="num" :class="cls(item.realChange)">
  <span :key="item.realChange" class="tick">
    {{ item.realChange > 0 ? '+' : '' }}{{ fmtNum(item.realChange, 2) }}%
    <i class="arw" aria-hidden="true">{{ item.realChange > 0 ? '▲' : (item.realChange < 0 ? '▼' : '') }}</i>
  </span>
</td>
```
```css
@keyframes tick-up   { from { background: rgba(255,138,111,.22) } to { background: transparent } }
@keyframes tick-down { from { background: rgba(0,200,100,.20)  } to { background: transparent } }
.tick { display:inline-block; border-radius:2px; padding:0 2px; }
.up .tick   { animation: tick-up .28s ease-out }
.down .tick { animation: tick-down .28s ease-out }
.arw { font-size:.7em; opacity:.75; font-style:normal; margin-left:1px }
/* prefers-reduced-motion 的全站降级（main.css:1578）已覆盖此处，无需额外写 */
```
  要点：**闪烁用背景色不用文字色**（文字色跳变会让整屏"花"）；箭头用小字号 + 低透明度，不抢色彩主次。建议先只上主表 3 列（现涨/竞涨/实体），观察后再推广到右表。
- **改动量**：**小**

### P1 · 体验明显问题

#### P1-1 1280px 以下**双栏直接塌成单列**（无中间档）
- **位置**：`main.css:225`（默认 `grid-template-columns:1fr`）+ `main.css:271-273`（`@media (min-width:1280px)` 才切 `minmax(0,1fr) minmax(0,1fr)`）
- **问题**：1024~1279 区间（老笔记本、1920 屏 @125% 缩放 = 1536 ✓ 尚可、1440 屏 @125% = 1152 ✗）**完全失去"左选股 + 右异动"同屏**，盯盘要整页滚动来回切 —— 与信息密度目标冲突。
- **建议改法**：
```css
@media (min-width:1024px){
  .home-cols{ grid-template-columns: minmax(0,1.15fr) minmax(0,1fr); }
  .home-col-right{ max-height: calc(100vh - 210px); }  /* 右栏自滚，左栏始终可见 */
}
```
  再给右栏加「折叠/展开」按钮（状态存 `localStorage`，与 `useTheme` 同套路）：盯盘者常在"只看结果表"与"双栏"之间切换，比强行挤两栏更实用。
- **改动量**：**小~中**

#### P1-2 数字格式不统一（**金额无千分位**、正负号不统一）
- **位置**：`src/utils/format.js:61-64`（`fmtNum = Number(v).toFixed(digits)+suffix`，**无千分位**）；全站 `toFixed(` **93 处** vs `toLocaleString` **4 处** vs `Intl.NumberFormat` **0 处**；`StockDetailPanel.vue:123` 单独用 `toLocaleString('zh-CN')`
- **问题**：竞价额 6168.86（万）、成交额、市值这类 5~7 位数字没有分隔符，位数靠数；同一屏内有的数字带 `+`、有的不带。
- **建议改法**（在 `format.js` 收敛，不动 93 个调用点也能先止血）：
```js
const nf = d => new Intl.NumberFormat('zh-CN', { minimumFractionDigits:d, maximumFractionDigits:d })
export const fmtNum  = (v, d=1, s='') => (v==null||isNaN(v)) ? '—'
  : (Math.abs(Number(v)) >= 10000 ? nf(d).format(Number(v)) : Number(v).toFixed(d)) + s
```
  规则建议：**|v| ≥ 10000 才上千分位**（小数字加逗号反而增噪）；百分比统一"符号 + 2 位小数"，方向另由 P0-3 的 ▲▼ 承担。改动量：**中**（先覆盖主表 7 列 + 指数条 + 情绪条）

#### P1-3 断点碎片化：**11 个不同断点**，768 一个扛 31 条
- **位置**：`{1280:2, 1099:1, 900:1, 899:2, 768:31, 700:1, 576:2, 560:1, 480:6, 430:2, 390:1}`（`main.css` 7 处、`AuctionView.vue` 5 处、`NewsView/AipickReport` 各 3 处）
- **问题**：`899/900`、`576/560`、`480/430` 成对出现 = 同一意图两处魔数，改一处必漏一处（历史上"横滑漏网点"就是这么来的，见 `main.css` 768 块注释）。
- **建议改法**：收敛为 5 档并在 `main.css` 顶部写清：
```
≥1280 桌面双栏 | 1024–1279 紧凑双栏 | 769–1023 单列宽表 | 481–768 手机(横滑) | ≤430 小屏卡片化
```
  另需**补 125% 缩放实测**：1440×900@125% → CSS 宽 1152 → 落"单列"，正是 P1-1 要兜的场景。改动量：**中**（建议分批 PR，勿一次性重排，避免重演 table sticky 回归）

#### P1-4 语义色硬编码 + 同类语义**两套红** + 重复样式已漂移
- **位置**：
  - 硬编码颜色：`main.css` **407 处**（典型：`:748` `.up{#ff8a6f}`、`:751` `.ratio-warm{#ffd700}`、`:1561-1567` 连板 5 档、`AuctionView.vue:1362/1413/1454-1463`）
  - **两套涨色**：全局 `.up{#ff8a6f}`（橙粉）vs 竞价表 `.real-chg-col.up{#ff5a5a}`（红）→ 同屏两种"涨"
  - 重复定义：`.lb-badge` 三份**逐字相同**（`AuctionView.vue:1316` / `MarketView.vue:620` / `YidongView.vue:438`）；`.spinner` **9 份**；`.lock-indicator` 同文件重复（`main.css:670` 与 `:691`）
  - 对比度唯一不达标项：`AuctionView.vue:1537` `.dim-25{color:#b06b6b}` → 面板底 **4.35:1**、叠水印后 **3.80:1**
- **建议改法**：① `:root` 补语义色（**不改现有红**）：`--up:#ff8a6f; --down:#00c864; --up-strong:#ff5a5a; --warn-amber:#d9822b; --star:#ffb400; --dim-soft:#c98a8a`；② 删掉 3 份 `.lb-badge`/9 份 `.spinner`，只留全局一份；③ 把 `dim-25` 换 `#c98a8a`（≥4.5:1）；④ 在 `frontend/_verify/` 加一条静态闸门（照 `css_scroll_guard.js` 的套路）禁止语义色裸值。改动量：**中**

#### P1-5 Font Awesome 4.7.0 走**公网 CDN**（render-blocking + 内网失效）
- **位置**：`frontend/index.html:29`（`<link rel="stylesheet" href="https://cdnjs.cloudflare.com/.../font-awesome/4.7.0/...">`）；用法遍布 **38 个 `.vue`**（如 `AuctionView.vue:10`）
- **问题**：head 里同步外链 CSS ⇒ **阻塞首屏渲染**；断网/内网/被墙 ⇒ 全站图标变方框；版本 7 年前。
- **建议改法**：本地化 + 子集化（只留实际用到的 ~15 个类，woff2 ≈ 6~10 KB）：
```css
@font-face{font-family:FontAwesome;src:url(/fonts/fa-subset.woff2) format('woff2');font-display:swap}
.fa{display:inline-block;font:normal normal normal 14px/1 FontAwesome}
.fa-bullhorn:before{content:"\f0a1"}  /* 按 grep 出的实际图标逐条列 */
```
  `font-display: swap` 保证图标后到不阻塞文字。改动量：**小~中**

#### P1-6 专业词**无悬停解释**（"实体/可信"对新手是黑盒）
- **位置**：`StockTable.vue:45`（实体 `<th>`）、`:48`（可信 `<th>`）等 **无 `title`**（全组件 `title=` 共 11 处，落到 `<th>` 的仅 **3 处**）
- **建议改法**：
```html
<th ... title="实体涨幅 = (现价 ÷ 今开 − 1) × 100%，衡量开盘后买盘是否延续">实体</th>
<th ... title="可信度 = 基准 65 + 竞价强度/换手/竞涨三项加成，区间 55~90">可信</th>
```
  用 `title` 或 `<abbr>`（后者可被读屏念出）；并把 `cursor:help` 加上（全站 `lb-tag` 已有此约定，见 `main.css:1560`）。改动量：**小**

#### P1-7 登录页定时器**未清理**（全站唯一确证的生命周期泄漏）
- **位置**：`frontend/src/views/LoginView.vue:141`（`countdownTimer = setInterval(...)`）、`:205`（`inviteTimer = setTimeout(...)`）；该文件 grep `onUnmounted|onBeforeUnmount` = **0**（其余 9 处手写定时器都有清理，如 `StockView.vue:422-429`）
- **建议改法**：
```js
import { onBeforeUnmount } from 'vue'
onBeforeUnmount(() => { clearInterval(countdownTimer); clearTimeout(inviteTimer) })
```
  并立约定：**新增 `setInterval/setTimeout` 必须落在 `usePolling` 或同文件清理块**（可在 ESLint 加 `no-restricted-syntax` 提醒）。改动量：**小**

#### P1-8 水印干扰**可量化**：把灰字从 6.95:1 拉到 5.50:1，并让 1 项跌破 AA
- **位置**：`frontend/src/components/Watermark.vue:80-88`（`.wm-layer{opacity:.18; z-index:2147483000; pointer-events:none}`）、`:20-44`（canvas 300×180，17px 主文字 `rgba(220,220,220,.65)`，-30° 平铺）
- **实测（WCAG 计算）**：水印笔画处把合成底色从 `#0a0c12` 抬到 `#23242a`：

| 文字 | 无水印 | 水印处（现 0.18） | 水印处（若 0.10） |
|---|---|---|---|
| 评分/可信/概念灰字 `#9a9a9a` | 6.95:1 | **5.50:1** | 6.19:1 |
| `--text-dim #8a8a8a` | 5.66:1 | **4.48:1（跌破 AA）** | 5.04:1 |
| `dim-25 #b06b6b` | 4.80:1 | **3.80:1** | 4.28:1 |
| 涨/跌 `#ff8a6f`/`#00c864` | 8.49 / 8.79:1 | 6.72 / 6.96:1 | 7.56 / 7.83:1 |

- **建议改法**：`opacity: .18 → .10`（灰字回到 6.19:1），同时把 `dim-25` 提亮（见 P1-4）。**不要**把水印挪到内容之下（防泄露目的），也别加 `filter: blur()`（截图仍可辨、观感更糊）。另注：水印时间戳是**生成时刻**的静态值（`Watermark.vue:22`），并不随时间刷新 —— 若要"防伪时间"需定时重绘，**建议不做**（会触发 canvas 编码 + 全屏重绘）。改动量：**小**

## 四、优先级最高的 3 件事

1. **P0-1 窄屏首列冻结（~10 行 CSS）** —— 决定"手机上能不能用"。横滑后不知道是哪只票，是盯盘场景的致命失误；改动极小、收益极大。
2. **P0-2 右栏多日表加行数上限 + `content-visibility`** —— 直接决定 30 s 轮询是否掉帧。当前每票 32 个 span 且无上限，是最大性能风险点。
3. **P0-3 数字变化闪烁（背景闪）+ 涨跌 ▲▼ 符号** —— 让"变了没有"一眼可见，同时把"颜色唯一编码"降级为"颜色 + 形状"双编码（色弱可用）。用 `<span :key="值">` + 一次 `@keyframes`，不加过渡、不引入动画库。

> 三件事都在 30 分钟内可落地、且不触碰算法与字段；建议同一次回归里一起上，回归重点：`StockTable.vue` 的 sticky 表头（已有 `--sticky-thead-top` JS 量高逻辑，见 `StockView.vue:402,406`）不要被冻结列的 `z-index` 盖住。
