## 四、加装方法

仓库副本在 `/tmp/skills-bundle/`（第一批）与 `/tmp/skills-b2/`（第二批），**/tmp 会被系统清理**。需要加装时：

```bash
# 重新克隆（浅克隆，秒级）
git clone --depth 1 https://github.com/<owner>/<repo>.git /tmp/x
# 找到含 SKILL.md 的目录，整体复制（必须连附属脚本一起）
cp -R /tmp/x/<path>/<skill> ~/.codebuddy/skills/<skill>
```

**注意三条**：
1. **必须整体复制目录**（`ui-styling` 带 98 个文件、`understand` 带 55 个，漏了脚本就跑不起来）
2. **改完要重启 CodeBuddy** —— 技能清单是启动时注入上下文的
3. 同名会冲突（`test-driven-development` 在 superpowers 与 agent-skills 里都有，只装了前者）
