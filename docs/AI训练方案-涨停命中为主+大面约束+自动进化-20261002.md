## 1. 目标口径（待主人确认，方案按建议值写）

**主目标（Primary）**：**涨停命中** = 当日**收盘封板**（`close ≥ up_limit`）。
　可选更严：区分"盘中触板"（`limit_history` 有 `zbc` 炸板次数）——建议**单列统计，不混入主目标**。

**约束 A：大面率（越小越好）**
1. 当日大面：收盘 ≤ **−5%**
2. 炸板回落：盘中触板但收盘距涨停 ≥ **5pp**
3. 次日大面：次日开盘 ≤ **−5%**（需先回填标签）
4. 追高大面：竞价涨幅 ≥7% 且收盘 ≤ 0

**约束 B：可买率（越低越要标注/降权）**
　竞价涨幅 ≥ 9.8%（一字/接近一字）视为"**不可买**"，单列分组或排序后置。

**报告指标（四条线统一）**：`命中率` / `大面率` / `可买率` / `期望收益（当日收盘卖、次日开盘卖）`，按 日 · 5 日 · 20 日 滚动。

## 2. 训练改造（模型侧）——按"性价比"排序，建议 P1 先做 ①②

### ① 样本权重 / 中间标签（最省事、收益最直接）
- 现状是**二值**：涨停=1、其余=0；"涨停后炸板 / 次日核按钮"与"横盘股"**同权** ⇒ 模型学不到"要避开大面"。
- 改成**三档软标签**：
  ```
  y = 1.0   收盘封板 且 不炸板
  y = 0.5   收盘封板 但 炸板回落 ≥5pp（或次日大面）
  y = 0.0   其余
  ```
  或等价的样本权重：`w = 1 + α·可买 − β·(历史同形态大面先验)`。
  > 注意：**大面是结果、不是 9:25 可知的特征**，所以只能在**目标/权重**里体现，不能当特征（否则泄漏）。

### ② 多标签（两个头），排序分融合
```
头 1：P(封板)            ← 主目标（保持现在的能力）
头 2：P(当日大面 ≤ −5%)   ← 风险头
头 3：P(次日不核按钮)      ← 需次日标签回填后启用
排序分 = P(封板) × (1 − w₁·P(大面)) × (1 − w₂·P(次日大面))
```
- `w₁/w₂` 由影子期表现自动校准（见 §4）。

### ③ 可买性处理
- 方案 A（推荐）：**不把它当特征**，只做**排序/展示约束**（不可买的票单列或后置），避免污染"命中"能力。
- 方案 B：**单独训练一个"可买版"模型**（训练时把竞价一字板样本剔除），与现模型并排出名单（"高命中组" + "可买组"）。

### ④ 分组排序学习（Group-wise Ranking）
- 把"每个交易日"作为一个 group，用 **LambdaRank** 直接优化"命中靠前 + 大面靠后"。
- 相对当前 point-wise 二分类，通常在同一天内的区分度上更有优势（需 A/B 验证）。

### ⑤ 规则/参数自动搜索（复用已有工具）
- `filter_search.py` 现在的目标函数是 `hit × ret`；**改成 `score = 命中率 − γ·大面率`**，网格加入：
  `竞价涨幅上限 {0,1,3,5,7,10}`、`竞价额下限 {0,500,1000,3000}`、`topN {3,5,10,30}`、`min_prob {0.5,0.6,0.7}`
- 保留现有的"前后半段同向"防过拟合过滤。

## 3. 数据侧补齐（P0，1~2 天）

1. **回填次日标签**：`update_next_day` 对全量历史补 `next_open_chg / next_close_chg`（本地库可算：用 `stock_kline` ✓ 无需出网）。
2. **四条线名单统一落库**（新建 `pick_daily` 表）：
   `date, line(金睛/火眼/精选/优选), code, rank, score, bid_change, bid_amount, buyable, is_limit_up, close_chg, next_open_chg, big_face_flags, model_version`
   —— 这是"自动进化"的**唯一事实来源**：没有它，就没法知道"哪条线在变好"。
3. **每日自动日报**（可推送到"我的"页/微信）：命中率、大面率、可买率、期望收益、与昨日/上周对比、异常告警。

## 4. 自动进化闭环（P1，3~5 天）

```
 09:27  预测 → 名单落库(带 model_version)                     ← 新增
 15:05  打标签（已有）→ 回填当日标签                            ← 已有
 收盘后 回填次日标签                                            ← 新增
 18:59  自动重训（已有）→ 自动滚动评估（2 个样本外窗口）        ← 评估自动化
        ↓
 晋级判定（全部满足才晋级）：
   ① 命中率 ↑ ≥ 1.0pp（20 日滚动）
   ② 大面率 不升 ≥ 0.5pp
   ③ 两个窗口同向（防单窗口过拟合）
   ④ 可买率 不低于基线 −2pp
        ↓
 影子期（1 个交易日）：新模型**只出名单、不推给用户**，次日用真实结果对拍
        ↓
 对拍通过 → 晋级为线上；不通过 → 自动回滚上一版模型（留档 + 一键人工回退）
```
**护栏（必须）**
- 单日最多晋级一次；连续 2 日劣化 ⇒ 自动冻结进化 + 告警（防止"越训越差"）
- 训练资源上限（测试机 1.75GB / 生产 7.5GB）与超时保护；训练失败 ⇒ 跳过，**绝不影响线上**
- 模型文件版本化留档（保留最近 N 版，可一键回退）
- 特征/模型宽度一致性断言（已有：`WIDTH_MISMATCH` 降级）⇒ 新特征必须与模型同批发布

## 6. 分阶段与验收

| 阶段 | 内容 | 工期 | 验收 |
|---|---|---|---|
| **P0** | 次日标签回填 + 四条线名单落库 + 统一日报（含大面率/可买率） | 1~2 天 | 能产出"昨日四线成绩单" |
| **P1** | 软标签/样本权重 + 多标签 + 规则目标改 `命中−γ·大面` + 影子期自动对拍 + 自动回滚 | 3~5 天 | 连续 10 个交易日：命中率 ≥ 现基线，大面率 ↓ ≥20%，可买率 ≥60% |

| **P3（可选）** | 真正"自动进化"：无人工介入的每日晋级（保留人工开关与熔断） | 视 P1/P2 效果 | 连续 20 个交易日无人工干预且不劣化 |

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 目标冲突（命中 ↔ 可买 ↔ 大面） | 明确优先序（建议：**可买是硬门槛 > 大面 > 命中数量**） |
