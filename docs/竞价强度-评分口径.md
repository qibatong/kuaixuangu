# 快选 · 竞价强度（第 3 评分维度 `warn`）评分口径

> 适用：竞价选股（`strategy=auction`）。实现唯一权威 = `backend/app/services/bid_strength.py`
> （合成入口 `_compose` → `score_one`；装载 `load` → `_fill_snapshot` / `_fill_ai` / `_fill_zb`）
> 本文所有数值均为 2026-09-30 生产库只读实测；配置口径以 settings 表 `scoring` 为准。

## 一、它在总分里的位置

| 项 | 值 |
|---|---|
| 维度 key | `warn`（历史名「异动等级」；2026-09-23 v7 起由「竞价强度」提供） |
| **权重** | **运行期（09-30 09:27 那批）= 0.35**；当前 settings = **0.17**（今日 15:32 / 18:00 / 18:04 三次 `PUT /api/admin/scoring` 改的） |
| 作用点 ① | 直接作为该维**档位分**（0~1 连续值，**不再二次分档**）→ 贡献分 = 强度 × 权重 × 100 |
| 作用点 ② | 置信度加成：强度 **≥ 0.85 → +10**（基准 65，钳制 [55, 90]） |
| 缺失时 | `warn` 因子走该表 default **0.18**（即强度四层全缺，如 899050/899601 今日） |

## 二、合成公式（`_compose`）

```
竞价强度 = clamp( w̃量比×量比档 + w̃净额×净额档 + w̃AI×AI档 + w̃昨比×竞昨比档 , 0.05 , 1.0 )

w̃ = 子权重**自动归一**后的值：w̃i = wi / Σw        （Σw ≤ 0 时硬回退 0.75/0/0.25/0）
四层**全为 None** → 返回 None（→ 上层 warn 走 default 0.18）
```

生产实际子权重（settings 未覆盖 `factors.bid_strength` ⇒ 用代码默认）：

| 子层 | 配置键 | **生效值** | 含义 |
|---|---|---|---|
| ① 竞价量比 | `w_vol_ratio` | **0.75** | 主信号 |
| ② 主力净额占比 | `w_ff` | **0.0** | 2026-09-23 v7 起权重并入量比（保留可一键恢复：写回 0.30 即回到 v6） |
| ③ AI 预测 | `w_ai` | **0.25** | 次级信号 |
| ④ 竞价昨比 | `w_zb` | **0.0** | 2026-09-30 新增，**默认关**（零回归） |

⇒ **当前实际只跑两层：量比 75% + AI 25%**（归一后无需缩放）。

## 三、四个子层：定义 / 来源 / 分档 / 缺失 default

| 层 | 数据来源（权威） | 口径 | 分档（`下限 ≤ 值 < 上限`，**首个命中**） | 缺失 default | 参与 |
|---|---|---|---|---|---|
| ① **竞价量比** | `snapshot_bid.auc_vol_ratio`（猫爪成品，落库取 2 位小数） | 标准口径 = **竞价成交量 ÷ 近 5 日平均每分钟成交量**；无值时**回退**「今 9:25 竞价额 ÷ 昨 9:25 竞价额」（昨额 < 100 万判不可用） | `≥3`→**1.00**；`2~3`→0.85；`1.5~2`→0.70；`1~1.5`→0.55；`0.6~1`→0.40；`<0.6`→0.25 | **0.22** | ✅ 0.75 |
| ② 主力净额占比 | `snapshot_bid.auc_main_net ÷ free_mv × 100`（%） | 分母必须是**自由流通市值**（与门槛/换手同口径） | `≥0.30`→1.00；`0.10~0.30`→0.85；`0.03~0.10`→0.70；`0.005~0.03`→0.55；`0.0001~0.005`→0.45；`-0.005~0`→0.30；`-0.03~-0.005`→0.20；`<-0.03`→0.10 | 0.35 | ❌ w=0 |
| ③ **AI 预测** | aipick XGBoost `ai_predict.ai_score_map`（本地推理） | **全市场概率降序 Top30** ∩ `p ≥ 0.80` 三档；低于所有档位下限 → 不进榜 | `0.90~1.01`→**1.00**；`0.85~0.90`→0.85；`0.80~0.85`→0.70 | **0.35（中性，不惩罚）** | ✅ 0.25 |
| ④ 竞价昨比 | `fetcher.fetch_yesterday_amounts`（昨日全天成交额，万元，与前端「竞/昨比」列同源同缓存） | 竞价额(万元) ÷ 昨日全天额(万元) × 100 | `≥7.66`→1.00；`4.03~7.66`→0.90；`2.62~4.03`→0.80；`1.94~2.62`→0.65；`1.50~1.94`→0.50；`1.05~1.50`→0.35；`<1.05`→0.20（边界按**候选池**分位定，非全市场） | 0.50 | ❌ w=0 |

**命中规则**：按列表顺序取**第一个**满足的档；一个都不命中 → 走该层 default（`_bucket` 实现）。

## 四、缺失语义（核心铁律）

- **缺失 ≠ 0**：每层**独立降级**，各自走 default；只有**四层全缺**才整体返回 None。
- `missing` 标记只记录 `bid_vol_ratio` / `ff_pct` 两层（AI 不在榜是常态、昨比缓存未热是常态，均**不标缺失**）。
- 因此「量比层缺」不等于「该维没分」：例今日 **001246 力勤资源**（新股）量比缺失 → 走 0.22，AI 命中 1.00
  ⇒ 强度 = 0.75×0.22 + 0.25×1.00 = **0.4150**（实测吻合）。
- 而 **899050/899601**（北证指数，误入快照）：量比/净额/AI/昨比全缺 → `score_one` 返回 **None** → warn 走 0.18。

## 五、生效路径 / 开关 / 可调项

| 项 | 说明 |
|---|---|
| 调用点 | `picker/pipeline.py::_load_strength` —— **只对粗筛候选**（≤200 只）加载，不跑全市场 |
| 跳过条件 | 物化（`precompute_read=1`）路径跳过（物化表 `warn_type` 已是档位）；`strategy=spot` 跳过（spot 六因子不含它） |
| 开关 | `settings.use_bid_strength`（生产 = `"1"`）；置 0 → 退回东财 f630 异动等级表 `[5,6)→1.00 / [4,5)→0.85 / [3,4)→0.60`（default 0.18） |
| 数据依赖 | 快照表（量比/净额）+ 本地 AI 模型；**不经东财** ⇒ 东财断连也能出分 |
| 可调键 | `settings.scoring.factors.bid_strength.{buckets,w_vol_ratio,w_ff,w_ai,w_zb,ff_buckets,ff_default,ai_buckets,ai_topn,ai_default,zb_buckets,zb_default}` |
| ⚠️ 注意 | 上述子键**不在管理端 `W_KEYS` 校验清单**里，但会被 `_build_scoring_cfg` **原样生效** —— 例如写 `w_ff=0.30` 就会"复活"净额层。改了要自己核对归一行为 |
| 静默窗口 | 猫爪静默（测试机 09:05-09:30）会拦掉量比来源 ⇒ 量比层缺失（AI 仍可用）⇒ 该维整体降级 |
