## 二、S1–S7 落地清单

### S1 匿名落地页（不再"落地即要登录"）
- 症状：未登录访问任意深链 ⇒ 302 到 `/login`，**21 条路由里只有 `/login` 对匿名可见**。
- 做法：① `router` 加匿名白名单；② 新增 `views/HomeEntry.vue` 按登录态 **`v-if` 互斥分流**（匿名走落地页、**不挂载 StockView**，从根上避免 401 硬跳转）；③ 新增 `views/LandingView.vue`（价值主张 + 6 项能力墙 + **读后端真实配额**的权益对照 + 双 CTA + 客服二维码 + 数据来源/免责）；④ `NavBar` 匿名不渲染一级 tab（那些 tab 全指向需登录页面 ⇒ 点了必被弹走，是"死链式点击"）。
- 验证：生产匿名实测 `hasLoginBox=false`、`微信扫码加客服`/`免费注册 · 领 5 天会员`/权益表真实数值均渲染。

### S2 浅色主题系统性修复
- 症状：浅色主题沿用深色语义色 ⇒ 首页 **435 处**、竞价异动 341 处对比度低于 AA；图表标题 `1.06:1`（≈不可见）。
- 根因（两个）：① `main.css` 浅色块缺 `--up/--down/--up-strong/--star/--warn-amber/--dim-soft/--brand-soft` **7 个语义色**；② **`--card` 从未定义**，而 5 处写了 `var(--card,#111826)` ⇒ 浅色下图表块仍是深底、文字按浅色主题取深灰。
- 做法：补齐 7 色 + 补 `--card`（浅色给纯白）+ `RotCharts` 内联 SVG/图例改走 CSS 变量（图表随主题切换）+ 琥珀叠琥珀的 `.auto-tag` 改不透明底。
- 验证：浅色首页违规 **435 → 3**、会员页 **0**；`/history` 图表标题与坐标轴恢复可读。

### S3 主按钮对比度
- 症状：`应用筛选` 深色 1.90:1、浅色 2.36:1（WCAG AA 需 4.5）。
- 🔴 关键：只改组件**没用** —— `main.css` 有两条 `body[data-bg="light"] .tdx-export-btn`（优先级 (0,2,1) > 组件 (0,2,0)）会把文字压成 `#333`/`var(--text-main)`。⇒ 两条全局规则加 `:not(.apply-btn)` 排除。
- 验证：直采计算样式 **5.36:1（两套主题）**。

### S4 开通/续费自助化
- 做法：可一键复制客服微信（`utils/contact.js` 单一来源）+ **价格卡（月卡 ¥218 / 季卡 ¥588，含"折合每天"）** + **客服二维码**（`components/ContactQr.vue`，5 处复用）+ VipGate 弹窗同款。
- 五处落点：我的会员·开通区 / 付费墙弹窗 / 落地页开通区 / 合规页底部 / 全站页脚（原生 `<details>` 向上弹出，零 JS 状态）。

### S5 首访减重
- 症状：首访 683 KB，其中 **CJK 字体 459 KB（14 个 woff2）**；入口 CSS 319 KB 含 **203 条 `@font-face`**（`@fontsource/noto-sans-sc` 两个全量子集 CSS 被静态 import 进入口）。
- 做法：移除全局静态 import；新增 **「系统字体」并设为默认**（`--font-system`：PingFang SC / HarmonyOS Sans SC / MiSans / Noto Sans CJK SC / 微软雅黑…，补 `tabular-nums` 保住数字对齐）；思源黑体/宋体/霞鹜等宽改为**选中才动态加载**。
- 验证：入口 CSS **319,101 → 83,898 B（−73.7%）**、`@font-face` **203 → 1**、默认路径字体请求 **0**。
- 附加（主人指令「统一」）：老账号**一次性收敛**到系统字体（`kuaixuan_font_unified_v1` 标记，只做一次、之后尊重用户选择）。验收用反证：预置 `fontFam:'lxgw'`，实测激活项仍是「系统字体」。

### S6 信任与合规
- 做法：合规页脚（用户协议 / 隐私政策 / 退款说明 / 联系客服 + 版权 + **备案位**）；新增 `views/LegalView.vue`（一组件三文档，`/terms`、`/privacy`、`/refund` 匿名可访问），**隐私政策按真实数据库字段撰写**；登录页补「注册/登录即表示同意《用户协议》《隐私政策》」。
- 🔴 两个常被忽略的点：① ICP 备案号 `const ICP = ''` **为空则整块不渲染**（绝不占位、绝不写假号）；② 退款口径由主人拍板为「**虚拟服务开通后不支持退款**」，只保留两条必要兜底（未成功开通/重复支付、平台原因持续不可用）。

### S7 SEO 与分享
- 做法：去 `noindex,nofollow`；补 `description` / `og:type,title,description,url,image` / `twitter:card` / `canonical`；静态标题「快选 · AI选股」→「快选 · 竞价选股」；`router` TITLES 补 4 个缺键并修掉「**快选 · 快选 竞价选股**」重复品牌词；`/bigv` 标题对齐导航「大V复盘」。
- 验证：外网 `robots="index, follow"`、OG 五项齐备、静态标题正确。

## 五、顺手修掉的既有缺陷

1. **`_verify/nav.spec.js` 的 localStorage 垫片**：判据是「`globalThis.localStorage === undefined`」，但 Node 22+ 起该对象**存在却是个空壳**（`getItem/setItem/removeItem` 都不是函数）⇒ 垫片从未安装、store 永远读成"未登录"、**该 spec 长期只能测匿名态**。改判据为「方法齐不齐」后，**9 项旧断言自动转绿**（261/18 → 273/9）。
2. **合规页 intro 的 `**加粗**` 原样显示**：`<p class="lg-intro">{{ doc.intro }}</p>` 没走 `rich()` ⇒ 生产实测 `/refund` 首屏能看到星号。已在**上生产后 2 分钟内**发现并热修（第二次换盘），新入口 `index-BPH7Cude.js`。

## 七、教训（写给下一个 agent）

1. **对比度不能只看 `getComputedStyle().color/backgroundColor`**：`body` 上是**渐变背景**，且半透明层需正确 alpha 合成 —— 否则会把「白底假设」带进去，产出几百条假阳性（本轮真实踩过，全量重算才定稿）。
2. **改不动样式先查"谁优先级更高"**：主按钮文字色被 `main.css` 的 `body[data-bg="light"] .tdx-export-btn`（0,2,1）压过组件里的 `.apply-btn`（0,2,0）——**只改组件永远不生效**。
3. **静态资源上线必须验 `content-type`**：`/wechat-qr.png` 专程验了 `image/png`（历史上有 `/fonts/*` 被 SPA 回退成 `text/html` 的事故）。
4. **发布后再用真浏览器点一遍首屏**：合规页 `**` 星号问题在 curl/构建阶段完全看不出来，是浏览器 dump DOM 才暴露的。
5. **测试断言用的垫片要跟着 Node 版本复核**："对象不存在"和"对象是空壳"是两回事。
