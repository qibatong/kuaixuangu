## 一、名单是怎么选出来的（可追溯链条）

```
picker.pipeline.run(strategy='auction')  ← 唯一选股链路
  ① 名单源   = 当日 9:25 定格快照 snapshot_bid（全市场 5923 只；定格时刻 09:26:30）
  ② 粗筛     = 板块/ST/昨涨停/竞涨区间/竞价额门槛 → 按**定格竞价涨幅降序**排队取前 200
  ③ 评分     = 5 维加权（见第二节）→ 总分 + 置信度
  ④ 精筛     = 市值区间 / 竞价额 / 定格竞价价上限 / 总分≥阈值 / 置信度≥阈值
  ⑤ 落库     = batches + batch_stocks（明细）+ stock_score_daily（评分与输入）
```

本批实际生效的筛选条件（`batches.filters` 原文，逐项翻译）：

| 落库键 | 值 | 含义 |
|---|---|---|
| `bidLt` / `bidGt` | 0（默认）/ 7 | **竞价涨幅 ∈ [0, 7] %** |
| `limitUp` | true | 含**昨日涨停**股 |
| `stSuspend` | false | 剔除 ST / 停牌 |
| `floatMvFloor` / `floatMvGt` | 20 / 200 | **自由流通市值 ∈ [20, 200] 亿** |

| `zh*` | — | 竞价精选（ZH）参数，本名单不适用 |

## 二、评分标准（本名单实际生效的那一版）

### 2.1 总分公式

```
base = w1·f1 + w2·f2 + w3·f3 + w4·f4 + w5·f5      # 每项 f 都是 0~1 的档位分
总分(probability) = clamp(base × 100, 5, 95) → 四舍五入取整
置信度(confidence) = clamp(65 + 3 项加成, 55, 90)
```

### 2.2 五个维度：定义 / 取值来源 / 权重（运行期 vs 当前）

| # | 维度(key) | 业务含义 | 取值来源（权威） | 单位 | **本名单权重** | 当前 settings 权重 |
|---|---|---|---|---|---|---|
| 1 | `bid` | 竞价涨幅（开盘撮合涨幅） | `snapshot_bid.bid_change`（9:25 定格） | % | **0.25** | 0.35 |
| 2 | `activity` | 竞价换手率（竞价资金参与度） | `snapshot_bid.auc_turnover`（猫爪官方成品，自由流通口径）；缺失时自算 竞价额÷自由流通市值 | % | **0.25** | 0.27 |

### 2.4 「竞价强度」= 本名单第 3 个维度的真实输入（唯一合成维度）

```
竞价强度 = 子权重归一后加权和 = 0.75 × 量比档 + 0.25 × AI档   （净额档 w_ff=0、昨比档 w_zb=0 均停用）
           再 clamp 到 [0.05, 1.0]
```

| 子层 | 数据来源 | 分档 |
|---|---|---|
| ① 竞价量比 | `snapshot_bid.auc_vol_ratio`（猫爪，竞价量÷近5日均每分钟量） | `3~9999`→1.00　`2~3`→0.85　`1.5~2`→0.70　`1.0~1.5`→0.55　`0.6~1.0`→0.40　`0~0.6`→0.25；default 0.22 |
| ② 主力净额占比 | `snapshot_bid.auc_main_net ÷ free_mv ×100`（%） | **w_ff = 0，本名单不参与**（保留可回退） |
| ③ AI 预测（aipick XGBoost） | 全市场概率 **Top30** 榜 | `0.90~1.01`→1.00　`0.85~0.90`→0.85　`0.80~0.85`→0.70；不在榜→0.35（中性，不惩罚） |
