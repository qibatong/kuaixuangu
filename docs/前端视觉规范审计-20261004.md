# 前端视觉规范审计（2026-10-04）

> 主人反馈「颜色/字体/字号很乱、页面不整洁」。本轮**只审计不改代码**，
> 用脚本量化全站（`frontend/src`，64 个 `.vue` + `main.css` 1684 行）的视觉令牌现状，
> 定位"乱"的具体来源，并给出可分批落地的收敛方案。

### 1.1 颜色：同一意图，N 个值（"乱"的主因）

**红色系（至少 7 种并存，肉眼几乎分不出差别）**

| 值 | 次数 | 语义 | 建议 |
|---|---|---|---|
| `#b83010` | 64 | 深红（暗底强调） | → `--brand-deep` |
| `#ff6a6a` | 33 | 浅红 | → `--brand-soft` |
| `#ff5252` | 16 | 红 | → `--brand` |
| `#c62828` | 16 | 深红 | → 并入 `--brand-deep` |
| `#ff5c5c` | 13 | `--accent` 变量值 | → `--brand`（保留） |
| `#ff3a3a` | 4 | `--accent-deep` | → `--brand-strong` |
| `#e5484d` | 4 | 品牌红调浅 | → 并入 `--brand` |
| `#ff8a6f` | 4 | `--up` 涨 | → `--up` |

**灰阶（10+ 种，且成对出现"同意图不同值"）**

```
#6b6b6b(34) ↔ #6b7280(28)     ← 同一"次要灰"，两个值
#888(31)     ↔ #8a8a8a(14)     ← 同一"弱化灰"，两个值
#999(16) / #aaa(10) / #9ca3af(19) / #5a4a3a(22) / #1f2937(15) / #f3f4f6(14)
```
而变量里其实**已经定义了** `--text-muted:#9a9a9a` / `--text-dim:#8a8a8a` —— 说明有变量但没人用，各组件自己写。

**黄色系 5 种**：`#ffb400`(68)、`#ffd700`(35)、`#ffe0a0`(26)、`#8a5500`(61)、`#c79100`(36)

**语义色变量本身也重复**（`main.css` 25–66 行）：
`--accent / --accent-deep / --accent-deep2 / --up / --up-strong / --warn-amber / --warn`
—— 红+橙共 **6 个语义相近**的变量，谁该用哪个没有规则 ⇒ 结果就是各写各的。

### 1.2 字号：84 种，且 rem / px 混用

```
主流(可保留)：0.75rem(336)  0.8125rem(149)  0.875rem(66)  0.6875rem(60)
              0.9375rem(30) 1rem(23)        1.0625rem(15) 1.25rem(14)
碎片(应删除)：0.6 / 0.62 / 0.64 / 0.66 / 0.68 / 0.7 / 0.72 / 0.7812 rem
px 混用：    10px(7) 11px(10) 11.5px(6) 12px(18) 14px(4) 18px(5)
```
- **≤0.7rem（≤11.2px）共 143 处** —— 手机上过密，10px 中文基本不可读；这是"看着乱/挤"的直接观感来源之一。
- **39 处 `0.75rem !important` + 6 处 `0.8125rem !important`** —— 靠 `!important` 压字号，说明选择器层级已失控（补丁叠补丁）。
- 根因：没有字号阶（type scale），每个组件"凭手感"给值。

### 1.3 浅色主题：219 处覆盖块 = 结构性问题

现在深色是"本体"，浅色靠 219 处 `body[data-bg="light"]` 逐条补丁覆盖。
⚠️ 这意味着：**每新增一个颜色，就要补一条覆盖规则；漏补 = 浅色模式下出现黑字黑底**。
硬编码之所以清不掉，一半原因在这 —— 改颜色要同时改两处，没人愿意动。

### 1.4 重灾区文件（按硬编码颜色数）

```
107  src/views/AdminView.vue
 90  src/views/AuctionView.vue
 66  src/components/StockChartModal.vue
 53  src/components/StockDetailPanel.vue
 51  src/views/MarketView.vue
 46  src/views/NewsView.vue
 36  src/views/YidongView.vue
```
这 7 个文件占全站硬编码约 **55%** —— 收敛工作按这个文件顺序做，投入产出比最高。

### 1.5 做得好的部分（别动）

- **字体族是统一的**：`body[data-font]` 三档切换（思源黑体 / 霞鹜文楷等宽 / 思源宋体），
  且数字列（股票代码/金额/涨幅）19 处固定等宽保证表格对齐 —— 这个设计是对的。
- **数字等宽特性**：`font-feature-settings: "tnum" 1,"lnum" 1` 已开，表格数字不歪。
- 零散问题只有：等宽字体栈有 **4 种写法**（`ui-monospace, monospace` / `ui-monospace, Menlo, Consolas, monospace` / `Consolas, Menlo, monospace` / `'Consolas'`）→ 统一成 1 个 `--font-mono`。

## 二、建议的令牌表（收敛目标）

### 2.1 颜色 —— 从 356 种收敛到 ~24 个语义变量

```css
:root {
  /* 品牌红（唯一红）*/
  --brand:        #ff5c5c;   /* 主：按钮/链接/强调      ← 吃 #ff5252/#e5484d */
  --brand-strong: #ff3a3a;   /* 强：涨停/强涨           ← 吃 #ff3a3a */
  --brand-deep:   #c62828;   /* 深：暗底文字/描边       ← 吃 #c62828/#b83010 */
  --brand-soft:   #ff6a6a;   /* 浅：次级强调            ← 吃 #ff6a6a */

  /* 涨跌（A 股习惯：红涨绿跌）*/
  --up:   var(--brand);      /* 涨 = 品牌红，不再单独定一档 */
  --down: #00c864;           /* 跌 */
  --flat: var(--text-3);     /* 平 */

  /* 黄/橙 */
  --star: #ffb400;           /* 星级/重点   ← 吃 #ffb400 */
  --gold: #ffd700;           /* 奖牌金      ← 吃 #ffd700 */
  --warn: #ff9632;           /* 警告        ← 吃 #ff9632/#d9822b */

  /* 文字 5 级（合并 10+ 种灰）*/
  --text-1: #eef2ff;         /* 主文 */
  --text-2: #c8ccd8;         /* 次级        ← 吃 #ddd */
  --text-3: #9a9a9a;         /* 弱化        ← 吃 #888/#999/#aaa/#8a8a8a/#9ca3af */
  --text-4: #6b7280;         /* 极弱/角标   ← 吃 #6b6b6b/#6b7280/#5a4a3a */
  --text-disabled: #4a4f5c;

  /* 面/线/态 */
  --bg-card, --bg-panel, --bg-input, --bg-hover, --bg-body;
  --border:        rgba(255,255,255,0.10);
  --border-strong: rgba(255,255,255,0.18);
  --success / --success-text / --success-bg;
}
```

### 2.2 字号 —— 84 种收敛到 8 档（全部 rem，最小 12px）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--fs-xs` | 0.75rem / 12px | 角标、单位、表头备注（**下限，不得再小**） |
| `--fs-sm` | 0.8125rem / 13px | 表格正文 |
| `--fs-base` | 0.875rem / 14px | 正文、按钮 |
| `--fs-md` | 0.9375rem / 15px | 小标题 |
| `--fs-lg` | 1rem / 16px | 卡片标题 |
| `--fs-xl` | 1.125rem / 18px | 区块标题 |
| `--fs-2xl` | 1.25rem / 20px | 页面标题 |
| `--fs-display` | 1.5rem / 24px | Hero / 大数字 |

删除：`0.6 / 0.62 / 0.64 / 0.66 / 0.68 / 0.7 / 0.72 / 0.7812 rem` 及所有 `px` 字号。
**移动端下限提到 12px**（现在是 9.6px，太挤）。

### 2.3 圆角 4 档（28 → 4）

`--r-sm:4px`（标签/徽章）· `--r-md:8px`（按钮/输入框）· `--r-lg:12px`（卡片/面板）· `--r-pill:999px`（胶囊）
`50%` 仅保留给头像/圆点。

### 2.4 阴影 3 档（43 → 3）

`--sh-1` 卡片 · `--sh-2` 下拉/浮层 · `--sh-3` 模态/抽屉。

### 2.5 间距 4px 栅格（210 → 6）

`--s1:4 --s2:8 --s3:12 --s4:16 --s5:24 --s6:32`

### 2.6 字重 3 档（现有 600/700 混用 221 处）

`400` 正文 · `600` 强调 · `700` 数字与标题（`800/900` 只在 hero 保留）

### 2.7 层级 5 档

`--z-sticky:100 --z-dropdown:1000 --z-modal:1100 --z-drawer:1150 --z-toast:1200`

## 三、落地计划（建议分 4 批，每批独立可回滚）

| 批次 | 内容 | 观感变化 | 风险 | 工作量 |
|---|---|---|---|---|
| **P0 令牌层** | 在 `main.css` 定义上述全套令牌（只加不改） | **无** | 零 | 小 |
| **P1 颜色收敛** | 红 7→4、灰 10→5、黄 5→3；按 1.4 文件顺序替换 | 轻微（同色系微调） | 低 | 中 |
| **P2 形/间距** | 圆角 28→4、阴影 43→3、字重统一、padding 走 4px 栅格 | 中等（明显变整齐） | 中（需逐页看） | 大 |
| **P3 字号阶** | 84→8 档；143 处 ≤11.2px 提到 ≥12px；清 `px` 与 `!important` | 中等（松快了） | 中 | 大 |
| **P4 主题重构** | 219 处 light 覆盖 → `body[data-bg="light"]` 里重定义变量（一处） | 无 | 中（一次性大改） | 中 |

> P4 建议**放在 P1 之后**：先把颜色收敛进变量，再重构主题，覆盖块数量会自然从 219 降到几十条。

**防回潮**：仿照已有的 `scripts/_verify/breakpoint_guard.js`，新增一个
`style_guard.js`：统计硬编码 hex / 字号种类数，**只允许减少，不允许增加**，接入构建前检查。
否则今天收敛完，下个功能又写回 `#ff5252`。

## 四、执行结果（2026-10-04 当天已实施 P0–P3）

工具：`scripts/_kx_style_converge.py`（`dry` / `apply [--shadow] [--spacing]` / `stat` / `check`）
三重安全边界：只改 `<style>` 段（`<script>` 里的图表色不动，写 `var()` 不生效）、
跳过 `:root` 定义块与 `body[data-bg="light"]` 块、颜色替换只发生在白名单属性内。

**计量口径**：只统计 `<style>` 段且排除 `:root` / light 块（早期的 356 种含 JS 图表色与浅色主题，口径偏大）。

| 维度 | 收敛前 | 收敛后 | 说明 |
|---|---|---|---|
| 裸色种类 | 196 | **154** | 剩余多为 `#fff`(50) 与结构性深色底（`#1f2937/#1a1a1a/#111826/#3a3f4b`），属刻意保留 |
| 字号种类 | 75 | **10** | 剩余全是 hero 级装饰大字（2rem~5rem）与 `inherit`/`0.72em` |
| 圆角种类 | 27 | **13** | 剩余多为多值写法（`8px 8px 0 0`） |
| 阴影种类 | 35 | **18** | 剩余多为 `inset` 与多重阴影 |
| 实际替换处数 | — | 颜色 304 + 字号 945 + 圆角 356 + 间距 1714 + 阴影 17 + 字重 27 | |

**新增令牌**（`main.css` :root）：`--brand-soft/deep`、`--gold-deep`、`--text-faint`、`--watermark`、
`--fs-xs..--fs-hero`（9 档）、`--r-sm/md/lg/pill`、`--sh-1/2/3`、`--s1..--s8`、`--z-*` 5 档、`--font-mono`。
沿用既有命名（不另起 `--text-1..4` 第二套别名）。

**棘轮闸门**：`python3 scripts/_kx_style_converge.py check`（或 `npm run style:guard`），
基线 `scripts/_verify/style_baseline.json` —— 裸值种类**只许减不许增**，下降自动下调基线。

**未做（P4）**：219 处 `body[data-bg="light"]` 属性覆盖 → 变量重定义。
风险中等且需逐页核对浅色模式，留到下一轮（先把颜色收敛进变量后，覆盖块数量会自然下降）。

## 五、一句话结论

> 不是"审美不好"，是**没有令牌约束**：356 种颜色、84 种字号、43 种阴影、210 种间距 ——
> 每个组件各自凭手感取值，整齐度自然无从谈起。
> 收敛到「24 色 / 8 字号 / 4 圆角 / 3 阴影 / 6 间距 / 3 字重」后，
> 页面整洁度会有**量级**提升，且后续加功能不会再劣化。
