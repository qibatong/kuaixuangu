## 五、缺失值契约（评分层的核心铁律）

- **缺失 = 未知 ≠ 0**：任何因子取不到值，一律走该因子 `default` 中性分，
  绝不冒充 0 落进分档桶（老链路把"市值缺失"当 0 → 落首桶拿满分 1.0）。
- **降级豁免**：当补丁数据源（东财/腾讯点查）全挂时，候选行只剩 9:25 定格字段，
  评分是"没数据可算"而非"这只票差" → 临时豁免 `scoreFloor` 评分门槛，
  其余门槛（板块/ST/竞涨/市值/竞额）不变。
- **评分构成不下发前端**：`parts` 各因子明细仅后端内部诊断/对拍用（主人要求保密）。
