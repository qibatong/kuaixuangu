# 训练口径「只有 40 天涨停基因一条」可行性评估（2026-10-07）

> 主人问：「训练口径，只有一个条件就是最近 40 天有过涨停的，你看下记录，评估是否可行」
> **结论：这正是当前已发布在跑的口径，可行性充分、且有实证优势。** 另发现一处可改进点（见第五节）。

`train_model.py` 就一行：

## 二、可行性证据链

| 指标 | 实测值 |
|---|---|
| 真实采集数据 | 184,312 行 / **34 天**（2026-08-10 ~ 09-30，单日 >3000 行） |
| 训练池（40 天涨停基因） | **30,642 行**，池内涨停率 **4.00%** |
| 训练/测试划分 | 训练 22,228 行（08-10~09-16）/ 测试 8,235 行（09-17~09-30） |
| 测试集 AUC | XGBoost **0.7546** / LightGBM **0.7564** |
| 实战（34 天真采集段） | 全市场 top30 **49.96%** vs 线上旧模型 46.03% |
| 池内 top5 | **42.14%** vs 旧模型 35.00% |

**最关键的反证 —— 基因池确实是有效信号**（本次新测，35 个有预测的日子）：

```
            实际涨停率
池内票     124/491 = 25.25%
池外票      14/126 = 11.11%      ← 只有池内的一半不到

近期（09-17 起 9 天）：
池内票      29/138 = 21.01%
池外票       1/ 10 = 10.00%
```

⇒ 「40 天内有过涨停」不是随手设的门槛，它**把命中率抬高一倍以上**。

## 三、为什么"只留这一条"在设计上是对的

报告附四已记录主人的道理，这里复述并补一条：

- **训练要覆盖全市场特征分布**：若把「涨幅≤7% + 市值≤200亿」塞进训练池，模型只见过池内那批票，
  学到的只是**池内相对排序**；一旦展示侧口径微调（金额门槛 3000 万 → 5000 万），
  模型输入分布就整体漂到训练分布之外。
- **补充判断：训练宽、展示窄是安全方向**。反过来的"训练窄、展示宽"才危险 ——
  那意味着模型要对自己从没见过的分布打分。
- 现状正是 **训练宽（4% 涨停率的基因池）+ 展示窄（金额/涨幅双门槛）** ⇒ 方向正确。

## 四、模型自身也在向池内收敛

每日名单里"池外票"的占比：

```
2026-08-07  96.7%   ← 早期（当时仍是旧口径/旧模型产物）
2026-08-17   5.9%
2026-09-04 ~ 09-24   多数日子 0%~10%
2026-09-28  10.0% / 09-29  6.7% / 09-30 14.3%
```

近一个月稳定在 0~14%，说明模型倾向于给出**训练时见过的分布**内的票。

## 五、⚠️ 发现一处可改进点（待主人定，本次未改）

**问题**：推理侧对**全市场 5561 只**打分，其中 **77.5% 在训练池外**：

```
2026-09-30  候选 5561 只 → 池内 1251 (22.5%) / 池外 4310 (77.5%)
2026-09-23  候选 5561 只 → 池内 1208 (21.7%) / 池外 4353 (78.3%)
```

而池外票的实际命中率只有 **11.11%**（池内 25.25%）⇒ **它们的分数不可信，却占用名单位置**。

**实测代价（35 天累计）**：池外票进了名单 126 只，其中命中仅 14 只（11%）⇒ **假信号约 112 只**。

**可选的修法**：在 `predict_daily.py` 的展示侧筛里**加上同一基因过滤**。

| | 收益 | 代价 |
|---|---|---|
| 名单质量 | 剔除命中率仅 11% 的池外票 | 会漏掉 14 只"池外但真涨停"的（占全部命中 138 只的 **10%**） |
| 性能 | 推理量 5561 → 1251，**快约 4 倍** | — |

⇒ **净收益明确**（去掉 112 个假信号 vs 牺牲 14 个真信号），但这是**展示口径变更**，需主人拍板。

## 六、如实记录的瓶颈

- **真实采集数据只有 34 天**（2026-08-10 起），这是样本量的硬上限；
- 更早的 98 天是 backfill 近似数据（`竞价额 ≈ 开盘价 × 量 × 0.15`，是编出来的），**不能用于训练**——
  实测混入后模型在真实分布上表现反而变差；
- ⇒ **随真实数据每天累积（+5,000 行/天）模型会持续变好**，这是提升模型的正路，比调因子、调阈值都管用。

## 七、⚠️ 一个必须知晓的影响面

**线上 AI 因子的权重当前是 0**：

```json
scoring.factors.bid_strength = {"w_vol_ratio": 0.6, "w_zb": 0.4, "w_ai": 0.0, "w_ff": 0.0}
```

2026-09-30 引入「竞价昨比」后，AI 的权重被让给了它 ⇒ **AI 不参与评分**。

所以本次训练口径的直接影响面是：**aipick 名单页（金睛 / 火眼）+ 页面展示的 `ai_prob` 数值**，
**不影响超智页「机会清单」的综合评分**。`ai_buckets` 已按新模型尺度改对，为将来重新启用 AI 时不留坑。
