# 影子 / 晋级 / 回滚闸门 + 历史回放演练（2026-10-03）

## 一、闸门设计（按主人裁决落地）

```
影子 SHADOW(≥20 交易日) ──命中+2pp 且收益改善──▶ 试运行 TRIAL(60 交易日) ──不劣──▶ 正式 OFFICIAL
        ▲                                            │
        └──────────── 大面率配对恶化 >3pp 直接拒 ─────┘        任一阶段：滚动 20 日双劣化 ×2 日 ⇒ FROZEN
```

| 项 | 值 | 说明 |
|---|---|---|
| 主判据 | 可买组**命中**（同日配对）≥ **+2.0pp** | 用点估计（非"显著"，理由见功效实测：20 日窗配对 MDE≈12.4pp） |
| 并列判据 | 按卖出规则模拟的**期望收益** ≥ 基准 | 回放中取 A 规则（次日开盘卖）；可换破板卖 |
| 大面率 | **监控 + 相对否决**：配对恶化 > **3.0pp** ⇒ 拒 | 单位统一为 pp |
| 影子/试运行 | ≥20 / ≥60 交易日 | 20 日闸门点估计、60 日复核"不劣（≥−1×SE）" |
| 防抖 | 滚动 **20 日**配对双劣化连续 2 日 ⇒ 冻结 + 告警 | 日级判定不可用（见下） |
| 护栏 | 单日最多晋级 1 次；训练失败不改线上（独立进程 + 原子切换） | 已实现 |
| 回滚 | 冻结/劣化 ⇒ 切回旧模型并告警 | 状态机 FROZEN + `frozen_reason` 留痕 |

脚本：`scripts/aipick/promotion_gate.py`（纯逻辑状态机，可单测）

## 二、历史回放演练（walk-forward，非固定切分）

设置：134 天数据；**初始训练 50 天**，随后 **84 天逐日对拍**（每 15 个交易日重训一次，只用该日为止的数据）
角色：线上 = 现网口径（11 维 BCE 等权）；影子 = v3 配方（LambdaRank 全样本 + 可买组 BCE 封板头名次平均）
口径：可买组 top10；配对差（同日）

| 结果 | 值 |
|---|---|
| 最终阶段 | **SHADOW（未晋级）** |
| 天数 | 83（每 15 天重训 6 次） |
| 动作统计 | shadow 83 / reject 0 / freeze 0 / promote 0 |
| 全程配对差 | 命中 **−0.36pp**、大面 +1.33pp、收益 −0.07pp/日 |
| 命中差最大值 | **+0.56pp**（闸门阈值 +2.0pp ⇒ 未达） |

🔴 **关键结论（自我纠偏）**：v3 配方在固定切分下看着很美（可买组 top3 58.3% vs 36.7%），但在 **walk-forward 真演练里并不优于线上模型**（−0.36pp）⇒ **闸门正确地拒绝了一次无效升级**。说明：
1. 固定切分（单一 20 日测试窗）会**放大**结果，必须用 walk-forward / 多窗口复核；
2. 当前 v3 配方**尚不足以晋级**，需要更长训练窗（演练中影子模型前期只有 50 天历史）+ 更多特征；
3. 闸门本身工作正常（保护了线上）。

## 三、演练抓出并修复的 3 个真 bug（这就是演练的价值）

| # | bug | 现象 | 修复 |
|---|---|---|---|
| 1 | **冻结规则过于灵敏** | 日级"连续 2 日双劣化"在命中率 sd≈22pp 下第 3 天就误冻结 | 改为**滚动 20 日**配对双劣化（≤−5pp 且收益为负）×2 日 |
| 2 | **阈值单位不一致** | 常量写 0.03、指标是 0.67pp ⇒ "0.67>0.03" 恒真 ⇒ 错误拒绝 52 次 | 全部统一为 **pp** |
| 3 | **NaN 对齐错位** | 收益 NaN 行过滤位置不当 ⇒ 分数数组与 df 错位（4773 vs 4767） | NaN 过滤移到驱动层，保持对齐 |

## 四、下一步
1. **延长训练窗**：影子模型用更长历史（至少 1 年）重训后再演练 ⇒ 判断配方是否真有效
2. **多窗口复核**：不看单一 20 日窗；用滚动多窗口的配对分布决策
3. 交易层规则先落地（破板卖 +1.08pp/日 已验证），与模型层解耦推进
4. 每日留存 minute 继续积累（供冲高卖/时间止损精确回放）
