## 四、⚠️ 顺带发现一个真实口径缺陷（建议修）

**"竞价涨停家数"的判定写死了 9.9%**：

```python
# backend/app/api/stats.py:222
"zt_count": (sum(1 for c in chgs if c >= 9.9) if chgs else None),
```

- 主板涨停 10% ⇒ `>=9.9` 能正确命中
- **但创业板/科创板涨停是 20%** ⇒ 一只创业板票竞价高开 **+12%**（**没涨停**）也会被算进"竞价涨停家数" ⇒ **系统性高估**
- 正确写法应**按代码取各自板块的涨停幅度**再判定（`chaozhi._limit_pct(code)` 已有同款实现，可直接复用）

这个数字目前只影响展示、不参与筛选，但它是"竞价温度"的关键指标之一，高估会误导判断。

## 八、✅ 已落地：P2「新」角标 + 中军改为成交额（2026-10-06 深夜）

### ① 主线雷达「中军」口径修正：涨幅次高 → **成交额最大**

主人指令"中军应该是成交额"，并授意核实行业定义。查证结果：

> "中军：通常是中大盘，流通盘足够大，**单日成交额往往位居板块前 3 名，占板块总成交额的 15%-30%**，
> 是大资金在板块里的主战场，能容纳几十亿甚至上百亿资金进出。"
> "龙头打高度，**中军打厚度**；龙头涨停但中军大跌 ⇒ 板块内部分歧，行情可能不健康。"

⇒ **旧实现（照抄旧独立页 `_pick_ld`：中军 = 涨幅次高）是错的** —— 那只是"第二强势股"，不含承接厚度。

**实测对比（线上真实板块）**：

| 板块 | 旧口径（涨幅次高） | 新口径（成交额最大） |
|---|---|---|
| 汽车零部件 | 众捷股份 +11.75% | **江淮汽车 成交 74.9亿（占板块 30%）** |
| 锂电池 | 兴业股份 +10.02% | **先导智能 成交 41.0亿（占 21%）** |
| 医药 | 康希诺 +20.0% | **百普赛斯 成交 28.1亿（占 12%）** |

新口径选出的成交额占比（江淮 30%、先导 21%）**正好落在行业定义的 15%~30% 区间**。前端同时把"成交 X 亿"标在中军后面 —— 它本来就是按这个选出来的，把依据亮出来才可核对。

### ② 龙头竞价榜「新」角标

判定 = **涨幅超出该股所属板块的涨跌停限制**（正常股票不可能超，只可能是上市首日/无涨跌幅限制）。金色中性底，**不用涨跌红绿**（它不是行情信号）。

**实测（09-30 9:25）**：`力勤资源 001246 +206.17%〔新〕`（上市首日）—— 榜首一眼可辨，不再与 +20% 的正常涨停混淆。

### ⚠️ 修正过程中的两个真实 bug（靠真实数据暴露）

实现后拿全市场数据实跑，发现两处误判：

| 现象 | 根因 | 修法 |
|---|---|---|
| `*ST禾信(688622) +14.0%` 被误标「新」 | 判定顺序错了：**先判 ST 再判板块** ⇒ 得 lp=5%。但**创业板/科创板的 ST 股涨跌停仍是 20%**（ST 5% 只适用主板） | 改为**先板块、后 ST**（`stats._limit_pct` 与 `chaozhi._limit_pct_of` 已同步） |
