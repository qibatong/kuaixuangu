# 点击个股「跳转通达信」问题 —— 全站排查与修复（2026-10-06）

> 主人反馈：不管电脑端、网页端还是手机端，**点击个股应当显示个股详情/分时，不应跳转通达信**。
> 本文是全站排查结果与修复记录。

---

## 一、根因（两层，都要修）

### ① `canLinkTdx()` 的判断范围太窄

```javascript
// frontend/src/utils/tdx.js（修复前）
export function canLinkTdx() {
  return !isNative()      // ← 只有"安卓壳"返回 false
}
export function linkToSoftware(code) {
  if (!canLinkTdx()) return
  showToast(`正在唤起通达信：${code}…`, 'info')
  setTimeout(() => { window.location.href = `http://www.treeid/code_${code}` }, 400)
}
```

⇒ **桌面 / 移动浏览器上，点个股会真实跳走**（唤起通达信客户端）。2026-10-04 只在安卓壳内屏蔽过，
判断范围不足。

### ② `App.vue` 的全局委托「选择器覆盖不全」

```javascript
// App.vue（修复前）
document.addEventListener('click', onDocClick, true)   // 捕获阶段，试图抢在 linkToSoftware 之前

function onDocClick(ev) {
  const cell = ev.target.closest('.stock-info-cell, .st-row-cell-code, .st-cell-code, td.code-click, .name-col, [data-stock-code]')
  if (!cell) return              // ← 匹配不到就返回，**不 stopPropagation**
  ...
  openStockChart(code, name)
  ev.stopPropagation()
}
```

**全站 16 处 `@click="linkToSoftware(...)"` 里，有 7 处不在这个选择器覆盖内** ⇒ 捕获阶段匹配不到
⇒ 不阻止事件 ⇒ **照旧跳通达信，而且详情也弹不出来**：

| 文件 | 绑定元素 | 是否被覆盖 |
|---|---|---|
| `MedalPanel.vue:9` | `.medal-code`（div）| ❌ |
| `HisPickPanel.vue:56` | `.medal-code`（div）| ❌ |
| `HisPickPanel.vue:147` | `.name-sub.code-click`（**非 td**）| ❌（选择器写的是 `td.code-click`）|
| `AuctionView.vue:161` | `.msd-cell.msd-name`（span）| ❌ |
| `SectorRotationPanel.vue:24` | `<tr>` 整行 | ❌ |
| `HotRankMulti.vue:18` | `<tr>` 整行 | ❌ |
| 其余 9 处（`.stock-info-cell` / `td.code-click`）| — | ✅ |

### ③ 更隐蔽的一处：`HisPickPanel` 自己实现了一套跳转

```javascript
// frontend/src/components/HisPickPanel.vue（修复前）
function linkToSoftware(code) {                 // ← 本地定义，**没有 import 模块版**
  if (!code) return
  const f = document.createElement('iframe')
  f.style.display = 'none'
  f.src = `http://www.treeid/code_${code}`      // ← 绕过 canLinkTdx，安卓壳也会跳
  document.body.appendChild(f)
  setTimeout(() => document.body.removeChild(f), 1000)
}
```

它用 iframe 触发跳转 ⇒ **连 `stopPropagation()` 都拦不住**（iframe 是自己创建并 append 的），
且完全绕过平台判断。

## 二、修复（一处核心改动，16 个调用点全部自动修正）

**把 `linkToSoftware` 改为与全局委托同一动作**（打开详情），而不是删掉 16 处调用：

```javascript
// frontend/src/utils/tdx.js（修复后）
import { openStockChart } from '../composables/uiBus'

export function canLinkTdx() {
  return false          // 全端禁用唤起通达信（保留函数与旧调用点，只关行为）
}

export function linkToSoftware(code, name = '') {
  if (!code) return
  openStockChart(code, name)    // = 打开个股详情（分时/K线）
}
```

**为什么用这个方案**：

- 全站 16 处调用**一次性全部纠正**，且**不碰任何模板**、零回归面
- 补上了那 7 处"原本既弹不出详情、又照跳通达信"的点位 —— 它们现在也能弹详情了
- `uiBus.js` 只依赖 vue，**无循环依赖**

**同时修 `HisPickPanel` 的本地实现**：删除，改用 `import { linkToSoftware } from '../utils/tdx'`。

**另外给 6 处缺失 `name` 的调用补上参数**（`<tr>` 整行、徽章等拿不到行上下文，
不传 name 弹窗标题会是空的）：`SectorRotationPanel` / `HotRankMulti` / `MedalPanel` /
`HisPickPanel`(2 处) / `AuctionView`(3 处) 共 8 处。

> 其余仍只传 `code` 的调用点（`.stock-info-cell` / `td.code-click`）**无需改** ——
> 它们在全局委托覆盖内，全局委托会自己从行内提取名称。
