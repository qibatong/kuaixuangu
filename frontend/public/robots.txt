# 2026-10-05 (A1): 此前站点**没有** robots.txt —— nginx 的 SPA 回退(try_files ... /index.html)
#   会把 /robots.txt 当成未知路径返回 HTML 首页，爬虫拿到的是一段 HTML 而不是指令。
#   本次补齐，并显式排除「登录墙内页面」。
#
# ⚠️ 为什么除 / 与三张合规页之外全部 Disallow：
#   全站除落地页外**均需登录**（router/index.js:125 PUBLIC_ROUTES 只放行 stock/terms/privacy/refund），
#   爬虫抓到 /ladder、/lhb 等只会被 302 到 /login ⇒ 在 Search Console 里堆一堆
#   「网页会重定向」软 404，既浪费抓取配额又拉低整站质量分。
#   等哪天匿名可读首屏真数据了，把对应路径从这里删掉即可（勿忘同步 sitemap.xml）。
